# 🖼️ Image Slider

A responsive image slider built with **HTML, CSS, and Vanilla JavaScript**.

## ✨ Features

* Previous / Next navigation
* Clickable image thumbnails
* Active image indicator
* Dynamic image counter
* Responsive design
* Smooth transitions
* Mobile-friendly layout

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6+)
* CSS Grid & Flexbox
* DOM Manipulation
